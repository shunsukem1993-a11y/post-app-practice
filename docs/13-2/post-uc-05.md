#### UC-01: ユーザー登録をする

- **アクター**: 訪問者
- **事前条件**: なし
- **基本フロー**:
  1. 訪問者がユーザー登録画面にアクセスする
  2. システムがユーザー登録画面を表示する
  3. 訪問者がユーザー情報を入力し、「登録」ボタンを押す
  4. システムがユーザー情報を登録し、完了メッセージを表示し、投稿一覧画面に遷移する
- **代替フロー**:
  - 3a. ユーザー情報（氏名、メールアドレス、パスワード）が未入力の場合、：システムはエラーメッセージを表示し、ユーザーを登録しない
  - 3a. メールアドレスがメール形式でない場合：システムはエラーメッセージを表示し、ユーザーを登録しない
  - 3a. メールアドレスが8字以内の場合：システムはエラーメッセージを表示し、ユーザーを登録しない
  - 3a. すでに登録されているメールアドレスの場合：システムはエラーメッセージを表示し、ユーザーを登録しない
- **事後条件**: ユーザーが1件登録される
- **受け入れ条件**:
  - [ ] ユーザー登録画面に「登録ボタン」が表示される
  - [ ] 氏名、パスワードのどちらかが未入力で登録しようとすると、エラーメッセージを表示し、ユーザーは登録されない
  - [ ] メールアドレスがメール形式以外で登録しようとすると、エラーメッセージを表示し、ユーザーは登録されない
  - [ ] メールアドレスが8字以内で登録しようとすると、エラーメッセージを表示し、ユーザーは登録されない
  - [ ] すでに登録されているメールアドレスで登録しようとすると、エラーメッセージを表示し、ユーザーは登録されない

- **事後条件**: なし
- **受け入れ条件**:
  - [ ] ログイン画面に「ログイン」が表示される
  - [ ] 氏名、パスワードのどちらかが未入力で登録しようとすると、エラーメッセージを表示し、ユーザーはログインされない

#### UC-03: ログアウトする

- **アクター**: ログイン済利用者
- **事前条件**: 投稿者としてログインしている。
- **基本フロー**:
  1. システムが投稿一覧画面で「ログアウト」ボタンを表示する
  2. ログイン済利用者が投稿一覧画面で「ログアウト」ボタンを押す
  3. システがログイン画面に遷移する
- **代替フロー**:なし
- **事後条件**: 投稿者が未認証状態になる
- **受け入れ条件**:
  - [ ] 投稿一覧画面に「ログアウト」が表示される

#### UC-04: 投稿一覧を表示する

- **アクター**: ログイン済利用者
- **事前条件**: 投稿者としてログインしている。
- **基本フロー**:
  1. ログイン済利用者が投稿一覧画面にアクセスする
  2. システが投稿一覧画面を表示し、自分の投稿のみ「編集」ボタン、「削除」ボタンが表示される
- **代替フロー**:なし
- **事後条件**: なし
- **受け入れ条件**:
  - [ ] 投稿一覧画面に投稿一覧を表示される
  - [ ] 自分の投稿のみ「編集」ボタン、「削除」ボタンが表示される

#### UC-05: 投稿を編集する

- **アクター**: ログイン済利用者
- **事前条件**: 投稿者としてログインしている。ログイン済利用者が投稿している
- **基本フロー**:
  1. ログイン済利用者が投稿一覧画面の「編集」ボタンを押す
  2. システが投稿編集画面を表示し、編集内容記入欄と「編集」ボタンが表示される
  3. ログイン済利用者が編集内容を記入し、「編集」ボタンを押す
  4. システムが投稿を編集し、完了メッセージが表示され、投稿一覧画面に遷移する
- **代替フロー**:
  2a. 他人の投稿のURLにアクセスすると403になる
  3a. タイトル、本文のいずれがが未入力で登録しようとすると、エラーメッセージを表示し、投稿が編集されない
- **事後条件**: 投稿が編集され、一覧画面に表示される
- **受け入れ条件**:
  - [ ] 投稿編集画面を表示し、編集内容記入欄と「編集」ボタンが表示される
  - [ ] 他人の投稿のURLにアクセスすると403になる
  - [ ] タイトル、本文のいずれがが未入力で登録しようとすると、エラーメッセージを表示し、投稿が編集されない

#### UC-06: 投稿を削除する

- **アクター**: ログイン済利用者
- **事前条件**: 投稿者としてログインしている。ログイン済利用者が投稿している
- **基本フロー**:
  1. ログイン済利用者が投稿一覧画面の「削除」ボタンを押す
  2. システが投稿削除画面を表示し、「削除」ボタンが表示される
  3. ログイン済利用者が「削除」ボタンを押す
  4. システムが投稿を削除し、完了メッセージが表示され、投稿一覧画面に遷移する
- **代替フロー**:
  2a. 他人の投稿のURLにアクセスすると403になる
- **事後条件**: 投稿が削除され、一覧画面に表示されない
- **受け入れ条件**:
  - [ ] 投稿削除画面を表示し、「削除」ボタンが表示される
  - [ ] 他人の投稿のURLにアクセスすると403になる
